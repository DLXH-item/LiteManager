轻量软件管理器 v2.0 —— 单文件绿色版（约 88 KB，无需安装）

【启动】
双击「轻量软件管理器.exe」，首次会弹一次 UAC 提示（卸载软件、清理注册表需要管理员权限），点“是”即可。
程序不联网、不上传任何数据。

【一、软件管理】
列出本机全部已安装软件（名称 / 版本 / 发布者 / 大小 / 安装日期 / 安装位置 / 状态）。
顶部左侧有搜索框：输入软件名、发布者、版本或安装路径的关键字，列表即时过滤；
  清空搜索框恢复全部，右上角显示已安装软件数与疑似流氓软件数。
还有“刷新列表 / 强制全量卸载 / 全选 / 取消全选”。
点任一列标题可排序（再点一次反向）：名称、版本、发布者、大小、安装日期、安装位置、状态。
勾选一个或多个，点“强制全量卸载”。执行顺序：
  1. Windows Installer 软件走 msiexec 静默卸载；普通安装器自动识别 Inno / NSIS 等静默参数；
  2. 深度残留清理（v1.8 新增，v1.9 全量加强）：
     关键词来源（v1.9 新增）：软件显示名、注册表卸载键名（如 ...\Uninstall\Doubao → Doubao）、
        安装目录名、卸载程序所在目录、图标路径、静默卸载程序目录。
        这解决了「中文显示名 + 英文目录」的软件（如显示“豆包”而数据目录叫 Doubao）。
     ① 安装目录与卸载程序所在目录：先结束占用进程，再清只读、takeown 接管、
        icacls 授权、逐文件强删、rd /q /s 兜底；失败自动重试 3 轮，被占用文件也能清；
     ② 用户级目录：%LocalAppData% / %AppData% / %LocalLow% / %ProgramData% /
        Temp / Programs / Packages，外加 C:\Users\<用户名> 根目录与「文档」目录下软件自建的
        同名数据目录（如 C:\Users\xxx\Doubao）。匹配「同名 / 同名前缀 AppName70、
        AppNameCache、AppNameLinkRouter / 驼峰附属组件」；C:\Users 下的联接点、
        系统外壳目录（Desktop / Documents / Downloads 等）与 .ssh 这类配置目录一律跳过；
     ③ 注册表：HKCU / HKLM 的 Software（含 WOW6432Node）、Software\Classes 下同名键、
        厂商键内的同名子键、删空后残留的空壳父键（协议处理器、右键菜单残留一并清）；
     ④ 开机启动项：Run / RunOnce（含 WOW6432Node）里名称或路径指向该软件的项，
        启动文件夹里的同名快捷方式；
     ⑤ 系统服务：ImagePath 位于安装目录之下的服务，先 sc stop 再 sc delete；
        只有服务名与关键词也吻合时才按 exe 名判断，避免误删别人的服务；
     ⑥ 计划任务：内容引用安装目录的任务，schtasks /delete /f；
     ⑦ 开始菜单、桌面等位置的快捷方式、%TEMP% 下的同名临时文件；
     ⑧ 按进程名结束软件常驻进程（如 Doubao.exe），跳过系统进程与本程序自身；
     ⑨ 删完逐项校验，仍被占用的会写进结果框，提示重启后重试。
  安全阀（v1.9 新增）：安装目录若被软件写成 C:\Program Files、C:\、用户目录、AppData 这类
    公共目录，会被判定为“不可删”，跳过目录删除与服务/任务匹配，绝不整目录删掉。
  属于系统组件目录（C:\Windows）的软件同样跳过目录删除。
读取列表、卸载过程中顶部都有进度条，右侧文字显示“正在卸载 i/N · 当前操作”。
卸载结束后弹出结果框，逐条列出删掉的目录、注册表键、服务、任务。
双击任意一行可打开它的安装位置。

【二、疑似流氓软件】
按多维度打分，不会自动动手，只有你勾选并点“卸载选中”确认后才执行：
  无发布者信息 / 发布者为未知 / 缺少卸载入口 / 无卸载命令也无安装目录 /
  安装在临时或下载目录 / 名称含推广词（助手、卫士、管家、加速、全家桶、破解、去广告等）/ 主程序无数字签名。
分数 ≥45 才进入该列表，≥70 标记为高风险（红色）。Microsoft / Windows 自家组件不会误报。
可勾选“仅显示高风险(≥70)”过滤。卸载同样有顶部进度条，同样执行上面的深度残留清理。

【三、文档管理】
打开软件后会自动开始全盘扫描，不用手动点。范围是全部本地固定磁盘（C 盘、D 盘等），
  自动跳过 Windows、Program Files、ProgramData、回收站、System Volume Information 等系统目录。
  扫描中按钮变成“停止”可随时中断，也可点“全盘扫描”重新扫一遍；扫描期间顶部显示滚动进度条。
文档管理只放文字类文件：Word 文档、Excel 表格、PPT 演示、PDF 文档、文本文件、其他文档，
  用下拉框切换分类（“全部文档”= 以上全部）。
点列标题可排序：文件名、类型、格式、大小、修改时间。
顶部有搜索框（文件名或路径关键字），还有“全选 / 取消全选 / 删除 / 彻底删除”。
每行最右侧有“转到”按钮，点一下跳到该文件所在文件夹并选中文件；双击行或按 Enter 同样效果。
勾选后可批量处理，只勾一个就是单个删除：
  “删除”= 移入回收站（可恢复）；
  “彻底删除”= 直接从磁盘抹除，不可恢复。
  遇到“访问被拒绝”“文件被占用”也能删：自动清只读/隐藏属性 → 找出并结束占用该文件的进程
    （Word、微信、看图软件等，系统关键进程不碰）→ 用 takeown/icacls 接管所有权并授予管理员完全控制
    → 仍然失败则用系统底层 del / rd 强删。被强制删除的文件不进回收站。
  被占用的文件若正开着未保存的内容，结束进程会丢失未保存修改，请先自行保存。
删除时顶部进度条按文件数推进，并显示“正在删除 i/N”。

【四、图片管理 / 视频管理 / 压缩文件管理】
三个独立页面，功能区完全相同（搜索框、列头排序、全选、取消全选、删除、彻底删除、转到按钮、进度条）。
排序字段：文件名、类型、格式、大小、修改时间。
图片：jpg / jpeg / png / gif / bmp / webp / tif / svg / heic / psd / raw 等；
视频：mp4 / avi / mkv / mov / wmv / flv / m4v / ts / rmvb / webm 等；
压缩文件：zip / rar / 7z / tar / gz / iso / cab / apk / jar 等。
删除规则、强制删除、进度条与文档管理一致。

【五、文件夹管理】
与文件扫描同一次完成，列出全盘所有文件夹（同样跳过系统目录），显示文件夹名和完整路径。
点“文件夹名”列标题可排序（升序 / 降序切换）。
顶部有搜索框、全盘扫描、“打开选中文件夹”。
每行最右侧有“打开此文件夹”按钮，点一下直接在资源管理器打开该文件夹；
  双击行、按 Enter、或选中多个后点“打开选中文件夹”，都能打开（一次最多打开 10 个）。

【提示】
列表显示全部结果，不再截断，条数和总大小写在右上角。
扫描过程中可以随意切换到其他页签，不会卡；扫描结束后当前页自动出结果，其他页切过去立即显示。
每页的勾选状态相互独立，切换页签不会丢。
勾选 / 取消勾选只重绘那一行，整张表不会闪白。

【六、锁文件 / 被占用 / 无权限文件（v2.0 新增）】
卸载或删除时，遇到 .lock / .lck / .lockfile / .lckfile 锁文件、无权限文件、被占用文件，一律按梯度强删：
  1. 结束占用该文件的进程（Restart Manager 精确查占用者，系统关键进程不碰）；
  2. takeown / icacls 接管所有权，授予管理员完全控制；
  3. cmd del /f /q 强删；
  4. 用「关闭即删除」（FILE_FLAG_DELETE_ON_CLOSE）独占句柄打开后立即关闭；
  5. 改名到同目录 ~lm_del_xxx 随机名再删（打破路径锁）；
  6. 仍被独占 → 登记到系统 PendingFileRenameOperations，重启时由系统在加载任何进程前自动删除，
     日志会写明「已登记重启后删除」。
锁文件扫描范围：%AppData% / %LocalAppData% / %LocalLow% / %ProgramData% / %TEMP% / C:\Users\<用户名>
  （含一、二级子目录），文件名命中软件关键词就删。
目录树删完仍有残留时，会逐文件 / 逐空目录登记重启删除，并汇总数量，不会假报成功。

【提醒】
卸载软件、彻底删除文件都不可撤销，执行前会弹出确认框并列出具体对象，请核对后再确认。
深度清理按关键词匹配残留，同名软件可能被一起清掉；程序已内置常用词与系统目录黑名单来降低误删。
第一次用建议先卸载一个不重要的软件，看结果框列出的对象是否正确。
